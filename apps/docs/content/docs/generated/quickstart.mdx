# Operator Quickstart

This is the current Ronin flow.

## 1. Connect GitHub

Install the Ronin GitHub App on the org or selected repositories.

Ronin stores the installation, syncs accessible repos, and mints short-lived installation tokens only when a run needs repo access for compare and PR API calls.

## 2. Watch a repo

Choose a repository from the installed GitHub App scope.

Ronin creates runs for onboarding and GitHub events, then stores artifacts such as workspace patches, PR links, support answers, and audit events.

## 3. Map support channels

Map a Slack channel, Slack DM, Telegram chat, or Telegram topic to a watched repo.

When a message arrives, Ronin resolves the channel to org and repo context before the agent runs. The agent should not guess which codebase the user means.

## 4. Ask for an answer

Example Slack message:

```text
@Ronin what is this project about?
```

Ronin routes the message to the mapped repo, invokes the execution agent with repo/artifact context, and stores a support answer artifact.

## 5. Ask for a repo change

Example Slack message:

```text
@Ronin Please add a short README section named Environment configuration explaining how to point the dashboard at a custom API, and open a PR.
```

Ronin classifies this as a workspace request, starts a Centaur execution, clones the repo, lets the agent edit files, runs checks, pushes a Ronin branch, and opens a GitHub PR.
