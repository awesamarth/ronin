## Security boundary

Ronin keeps long-lived secrets on the backend.

The sandbox receives only the short-lived GitHub App installation token needed for the scoped repo clone and branch push. The GitHub App private key, Slack token, Telegram token, and database credentials stay outside the sandbox.

## Product behavior

- GitHub App install defines repo access.
- Channel mappings define which repo a support conversation belongs to.
- Ronin stores runs, artifacts, PR links, and audit events.
- Hermes performs implementation work only after Ronin resolves org, repo, channel, and allowed action.
- PRs are opened from real sandbox file edits, not generated report placeholders.
