# Run Report

Ronin is an agentic solutions engineering control plane around the execution agent.

Ronin can take a real company context, route work to the right repo, run the agent through Centaur, and return an auditable GitHub PR.

## Security boundary

Ronin keeps long-lived secrets on the backend.

The Centaur agent receives a `GITHUB_TOKEN` scoped to the repo clone and branch push. Configuring this token in Centaur is an operator requirement; Ronin does not provision it. The GitHub App private key, Slack token, Telegram token, and database credentials stay outside the agent. Ronin never passes a GitHub installation token through prompts, metadata, session messages, or the Centaur API.

## Product behavior

- GitHub App install defines repo access.
- Channel mappings define which repo a support conversation belongs to.
- Ronin stores runs, artifacts, PR links, and audit events.
- The agent performs implementation work only after Ronin resolves org, repo, channel, and allowed action.
- PRs are opened from real workspace file edits, not generated report placeholders.
