# Ronin Docs

Ronin gives protocol and devtool teams an always-on agentic solutions engineering lane.

Install the GitHub App, map support channels to repos, and Ronin starts routing work through the execution agent. Ronin owns tenant context, repo permissions, artifacts, audit logs, and product policy. The agent does the actual repo inspection and implementation work through Centaur: the operator configures Centaur with a scoped GitHub token, and it clones repos, runs checks, commits, and pushes.

Ronin does not replace solutions engineers. It offloads the repetitive parts: repo inspection, docs drift, support triage, example updates, first-pass fixes, and PR creation. Humans stay in the loop for architecture, customer judgment, merges, and deploys.

## What Ronin does today

- Watches repositories installed through the Ronin GitHub App.
- Turns GitHub events into Ronin runs with stored artifacts and audit logs.
- Answers Slack and Telegram support messages using mapped repo context.
- Converts clear support requests into Centaur-driven code/docs changes and GitHub PRs.
- Runs focused checks (install, lint, build, tests) through Centaur when available.
