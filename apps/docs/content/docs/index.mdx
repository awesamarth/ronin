# Ronin Docs

Ronin gives protocol and devtool teams an always-on agentic solutions engineering lane.

Install the GitHub App, map support channels to repos, and Ronin starts routing work through Hermes. Ronin owns tenant context, repo permissions, artifacts, audit logs, and spend gates. Hermes does the actual repo inspection and implementation work inside the NemoHermes/OpenShell sandbox.

Ronin does not replace solutions engineers. It offloads the repetitive parts: repo inspection, docs drift, support triage, example updates, first-pass fixes, and PR creation. Humans stay in the loop for architecture, customer judgment, merges, deploys, and spend approval.

## What Ronin does today

- Watches repositories installed through the Ronin GitHub App.
- Turns GitHub events into Ronin runs with stored artifacts and audit logs.
- Answers Slack and Telegram support messages using mapped repo context.
- Converts clear support requests into sandboxed code/docs changes and GitHub PRs.
- Runs Bun install, lint, and build checks in the NemoHermes/OpenShell sandbox when available.
- Records budget-capped provisioning plans before any Stripe-backed spend.
